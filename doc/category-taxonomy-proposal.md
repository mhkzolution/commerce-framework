## Categories that should be merged

Do **not** merge `เสื้อผ้าและเครื่องประดับ` into `สินค้าและอุปกรณ์สำหรับเด็ก`. That is the current problem.

Do **not** merge เสื้อเด็ก with กางเกงเด็ก, or ชุดว่ายน้ำเด็ก with เสื้อว่ายน้ำเด็ก. Titles distinguish them (e.g. Shark Boys Swimwear vs Boys Swim Shirt).

Candidates to collapse *after* a tree exists, if merchandising prefers fewer nodes:

- **กางเกงเด็ก + กางเกงยีนส์เด็ก** if denim is only a filter
- **ชุดว่ายน้ำเด็ก + เสื้อว่ายน้ำเด็ก** as parent/child rather than siblings
- **เสื้อผ้าเด็กอ่อน** vs putting baby pants in กางเกงเด็ก — this proposal keeps garment type (Baby Organic Cotton Rib Pants → กางเกงเด็ก)
- **ของเล่นและเครื่องนอนการตกแต่ง** should be split, not merged further
- **หนังสือและดนตรี** should be split, not merged further

Examples of ambiguous / low-signal titles:

- `ชุด - adidas` → clothing parent, not เสื้อเด็ก
- `The happiest baby on the block` is a **book** (now 93% after the parenting-title rule)
- `Rainbow Skirt One Piece Suit ชุดว่ายน้ำ…` is swimwear, not a dress
- `T-Shirt … ที่กระเป๋า` is a tee with a pocket print, not a bag
- `Costume Dress Up Shoes` is **shoes**, not ชุดแฟนซี
- `Swim Vest / เสื้อชูชีพ` is safety gear, not เสื้อว่ายน้ำเด็ก

---

## Method

- Title only (English + Thai). No images, no attributes, no short description used in the first pass.
- Specific garment beats generic kids catch-all.
- Swim shirt before swim set; jeans before pants; shoes before costume; life vest before jacket.
- `ชุด` in Thai is overloaded (outfit, pajamas, swimwear, costume). Those stay parent-level unless a type word is present.

No products were changed.
